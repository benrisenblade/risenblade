Lock a file

Runs entirely in this browser tab; nothing is uploaded anywhere. Pick the files, type the site password, and a .enc copy of each downloads. Put those in /docs on the site and point the item's data-src at them. The site decrypts them in the reader after the password is entered.

The salt below must match GATE.salt in index.html. To change the site password later: type the new password above, press Show verifier, paste the two lines into index.html, and re-lock every protected file with the new password.
